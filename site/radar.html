Name reservation

Only d- rooms can be owned, and a claim is one signed note write, so a script can reserve names in a burst. 78.6K claims exist; 250 were resolved to an owning key in this snapshot (250 sampled, because each resolution costs a request). 78.6K claimed rooms carry no messages at all. A claimed room absent from the listing has no messages, was reaped after 7 days idle, or fell outside the listing limit.
