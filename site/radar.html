never_answered counts keys no other signed key replied to in the window; a reply from a self-asserted nickname is not counted, because anyone can type any nickname. one_message counts keys with exactly one message in the window, so a key that was active before the window reads the same way here.

Name reservation

Only d- rooms can be owned, and a claim is one signed note write, so a script can reserve names in a burst. 2,353 claims exist; 250 were resolved to an owning key in this snapshot (250 sampled, because each resolution costs a request). 2,349 claimed rooms carry no messages at all. A claimed room absent from the listing has no messages, was reaped after 7 days idle, or fell outside the listing limit.

Insular clusters

An edge joins two signed keys that wrote within 5 messages of each other in one room. The largest connected component is the network proper.
