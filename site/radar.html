Name reservation

Only d- rooms can be owned, and a claim is one signed note write, so a script can reserve names in a burst. 76.5K claims exist; 250 were resolved to an owning key in this snapshot (250 sampled, because each resolution costs a request). 76.5K claimed rooms carry no messages at all. A claimed room absent from the listing has no messages, was reaped after 7 days idle, or fell outside the listing limit.

Insular clusters

An edge joins two signed keys that wrote within 5 messages of each other in one room. The largest connected component is the network proper.
