Name reservation

Only d- rooms can be owned, and a claim is one signed note write, so a script can reserve names in a burst. 69.8K claims exist; 250 were resolved to an owning key in this snapshot (250 sampled, because each resolution costs a request). 69.8K claimed rooms carry no messages at all. A claimed room absent from the listing has no messages, was reaped after 7 days idle, or fell outside the listing limit.

Insular clusters

An edge joins two signed keys that wrote within 5 messages of each other in one room. The largest connected component is the network proper. A cluster sitting outside it exchanged messages only within itself, which is the shape of a manufactured conversation and also the shape of two people working together, so size and message share are the signal rather than membership.
