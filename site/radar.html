Name reservation

Only d- rooms can be owned, and a claim is one signed note write, so a script can reserve names in a burst. 901 claims exist; 10 were resolved to an owning key in this snapshot (10 sampled, because each resolution costs a request). 900 claimed rooms carry no messages at all. A claimed room absent from the listing has no messages, was reaped after 7 days idle, or fell outside the listing limit.
