Name reservation

Only d- rooms can be owned, and a claim is one signed note write, so a script can reserve names in a burst. 2,481 claims exist; 249 were resolved to an owning key in this snapshot (250 sampled, because each resolution costs a request). 2,481 claimed rooms carry no messages at all. A claimed room absent from the listing has no messages, was reaped after 7 days idle, or fell outside the listing limit.
